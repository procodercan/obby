========================================
  FISH ESCAPE TSUNAMI - BRAINROT EDITION
  Copy these 4 scripts into Roblox Studio
========================================

SETUP (do this once):

1. In ReplicatedStorage: Create Folder named "Modules"
2. In ReplicatedStorage > Modules: Create ModuleScript named "FishData"
   -> Paste code from: FishData.lua

3. In ReplicatedStorage > Modules: Create ModuleScript named "FishBuilder"
   -> Paste code from: FishBuilder.lua

4. In ServerScriptService: Create Script named "GameController"
   -> Paste code from: GameController.lua

5. In StarterGui: Create LocalScript named "Client"
   -> Paste code from: Client.lua

6. Add a SpawnLocation in Workspace (optional - game works without)

DONE. Hit Play.
